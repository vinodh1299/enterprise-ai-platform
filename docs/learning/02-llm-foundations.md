# Phase 2: First LLM Integration & AI Principles

## Explain Like I'm 10
Imagine hiring a super-smart assistant who has read millions of books:
1. **Training vs. Inference:** 
   - **Training:** Spending years in school reading books (**Costly, done once by Google/OpenAI**).
   - **Inference:** Asking the assistant a question today (**Fast, cheap, done when you call the API**).
2. **Tokens:** LLMs don't read whole words—they chop sentences into word chunks called **Tokens** (like puzzle pieces). A word like `"Enterprise"` might be 2 tokens: `"Enter"` and `"prise"`.
3. **Temperature:** 
   - `Temperature = 0.0`: The assistant acts like a strict math teacher (gives the exact same rigid answer every time).
   - `Temperature = 0.7`: The assistant is helpful, clear, and natural.
   - `Temperature = 1.5`: The assistant acts like a wild poet (creative, unpredictable, slightly crazy).
4. **Why LLMs are NOT Databases (Hallucinations):** 
   - A database is a filing cabinet (returns exact stored rows).
   - An LLM is a pattern predictor (it predicts which word comes next based on probabilities). If it doesn't know an answer, it will confidently invent a plausible-sounding lie (**Hallucination**)!

## Technical Definition
* **Large Language Model (LLM):** A deep neural network based on the Transformer architecture, trained on massive textual corpora using auto-regressive next-token prediction objectives.
* **Tokens & Context Window:** Tokens are the atomic sub-word units generated by tokenizers (e.g., Byte-Pair Encoding). The Context Window defines the maximum sequence length of tokens (prompt + output) the model can process in a single inference call.
* **Temperature:** A hyperparameter scaling the logit outputs of the final neural network layer before applying Softmax probability distribution.
* **Token Economics:** LLM providers charge per 1,000 input (prompt) tokens and output (completion) tokens.

## Common Mistakes Beginners Make
1. **Confusing LLMs with Databases:** Assuming an LLM "knows" private company documents without passing them in prompt context (RAG).
2. **Ignoring Token Costs:** Sending massive 100,000-token prompts repeatedly without measuring cost or latency.
3. **Hardcoding System Prompts:** Not separating user queries from system instructions, exposing system prompts to prompt injection vulnerabilities.

## Interview Questions an AI Engineer Could Ask
1. **Q: What is the difference between Prompt Tokens and Completion Tokens in terms of cost and latency?**
   * *A:* Prompt tokens are processed in parallel during the prefill phase (faster per token), whereas completion tokens are generated auto-regressively one token at a time during decoding (higher latency per token). Providers often price completion tokens at 3x-4x higher than prompt tokens.
2. **Q: Why does setting Temperature to 0.0 not guarantee 100% deterministic outputs across hardware clusters?**
   * *A:* Floating-point non-determinism in parallel GPU/TPU matrix multiplications (such as atomic additions across threads) can cause tiny bit-level variations, leading the Softmax function to select different token paths occasionally even at temperature 0.0.
